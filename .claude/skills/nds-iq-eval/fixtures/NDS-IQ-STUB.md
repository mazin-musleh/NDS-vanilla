# NDS IQ — building UI with the National Design System

## The two paths

**`NDS_ROOT`** — the NDS template folder, extracted from one release zip.

**`NDS_ASSETS`** — the folder inside this project that the runtime assets are copied to.

`NDS_ROOT/NDS-INDEX.md` maps each need to that release's files.

## The rule

All UI in this project is built with NDS.
