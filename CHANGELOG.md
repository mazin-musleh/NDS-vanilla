# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### Fixed
- **Cards** — While a card loads, a row card with an image stays a row, a drawer in the card shows its own skeleton rows, a status card's icon turns grey, and a progress ring shows only its empty track.

## [2.0.0] - 2026-11-12

### Added
- **Audit** — Checks a page for silent failures and for names a release renamed or removed. See the [Audit](https://mazin-musleh.github.io/NDS-vanilla/core/audit.html) page.
- **Calendar** — Events by week or month, with Gregorian or Hijri dates. See the [Calendar](https://mazin-musleh.github.io/NDS-vanilla/components/calendar.html) page.
- **Cards** — Status cards, a flat look, and a corner slot for a tag or a small button.
- **Clock** — Shows the current time in the site's timezone. See the [Clock](https://mazin-musleh.github.io/NDS-vanilla/components/clock.html) page.
- **Cookies** — A Manage view with one switch per category, and a consent API for your own UI.
- **Countdown** — The time left until a deadline, as text or statistic cards. See the [Countdown](https://mazin-musleh.github.io/NDS-vanilla/components/countdown.html) page.
- **Dark areas** — Show any element and its content in dark mode.
- **Date** — Date tools for Gregorian and Hijri dates, with a site timezone, format and first day of the week. See the [Date](https://mazin-musleh.github.io/NDS-vanilla/components/date.html) page.
- **Date Picker** — Limits relative to today, disabled days, typing in the field's format, and a date value for the server.
- **Date Tile** — A date in a small box at the start of a list row. See the [Date Tile](https://mazin-musleh.github.io/NDS-vanilla/components/date-tile.html) page.
- **Examples** — Nine new pages, such as Student Portal, Events Calendar and Open Data.
- **Formatted Input** — Fields with a set shape and a check: phone, national ID, IBAN, VAT and vehicle plate. See the [Formatted Input](https://mazin-musleh.github.io/NDS-vanilla/components/formatted-input.html) page.
- **Forms** — A reset restores every NDS field, a sent form cannot submit twice, and a label can carry a Help tooltip.
- **Icons** — 20 more UI icons that paint with no font wait. See the [Icons](https://mazin-musleh.github.io/NDS-vanilla/foundations/icons.html) page.
- **Image** — Crops a photo to a set shape. See the [Image](https://mazin-musleh.github.io/NDS-vanilla/components/image.html) page.
- **Internationalization** — NDS words follow the page language, and change with it without a reload. See the [Internationalization](https://mazin-musleh.github.io/NDS-vanilla/core/i18n.html) page.
- **JavaScript API** — One set of methods to read, write and clear a field's value, and to destroy a component.
- **List** — A set of like items, each a card, as a grid or as rows. See the [List](https://mazin-musleh.github.io/NDS-vanilla/components/list.html) page.
- **Meta** — A line of short facts with icons under a title. See the [Meta](https://mazin-musleh.github.io/NDS-vanilla/components/meta.html) page.
- **National Day 96** — The official campaign hero for the event pack. See the [National Day 96](https://mazin-musleh.github.io/NDS-vanilla/events/national-day-96.html) page.
- **NDS IQ v4.0** — Rules for AI coding agents. See [NDS IQ](https://mazin-musleh.github.io/NDS-vanilla/guides/integration-quality.html).
- **NDS-INDEX.md** — Ships in the template zip and maps each need to this release's files.
- **Print** — A printed page keeps its content and drops the page chrome. See the [Print](https://mazin-musleh.github.io/NDS-vanilla/utilities/print.html) page.
- **Selection** — Select-all works on any list: table rows, cards or checkboxes.
- **Session Timeout** — A warning modal with a countdown before an idle session ends. See the [Session Timeout](https://mazin-musleh.github.io/NDS-vanilla/ui-shell/session-timeout.html) page.
- **Swiper** — Autoplay on a looping row, with an optional pause button. See the [Swiper](https://mazin-musleh.github.io/NDS-vanilla/components/swiper.html) page.
- **Template zip** — A script runs browser checks on your own pages.
- **Templates** — A Life Journeys hub for the services around a life event. See the [Life Journeys Template](https://mazin-musleh.github.io/NDS-vanilla/templates/life-journey-template.html).
- **Time Picker** — A time field the user types into or picks from. See the [Time Picker](https://mazin-musleh.github.io/NDS-vanilla/components/time-picker.html) page.
- **Timeline** — Dated events built on Stepper. See the [Timeline](https://mazin-musleh.github.io/NDS-vanilla/components/timeline.html) page.
- **Top Bar** — Expanders: a strip that slides open below the bar. The digital stamp is one.
- **Weather** — Shows the current weather for one place. See the [Weather](https://mazin-musleh.github.io/NDS-vanilla/components/weather.html) page.

### Changed
- **Accessibility** — The panel loads on first use, and follows the page's language.
- **Action rows** — Button rows in Card, Modal, Panel, Forms and Dropmenu wrap to the next line.
- **Browser support** — Filter and the Digital Stamp work in browsers from 2021.
- **Button** — Buttons fit their content, keep a minimum height, take the sizes you set, destructive buttons match the design and have their own dark look, and neutral buttons take the on-color look in dark mode.
- **Cards** — Cards fill their container, row cards stack when narrow, and default text colors and phone spacing changed.
- **Date Picker** — The calendar opens from its button and follows the language around it.
- **Definition List** — The default size is the side info look, and LG is gone.
- **Dropmenu and Tooltip** — They open in the browser's top layer, so nothing clips them.
- **Filter** — The URL and the request use one plain query, and a Date Picker group filters by date.
- **Flex** — The default gap is 8px.
- **Forms** — Clearer error messages, phone numbers submit in a standard form, and group spacing is tighter.
- **Icons** — The content icon font is the current Hugeicons set, and a page loads only the parts it uses.
- **JavaScript API** — Methods take an element, an id or a selector.
- **Link** — Links are primary by default everywhere.
- **Main Navigation** — The search box shows suggestion chips, and a click on one runs the search.
- **Modal and Panels** — Both use the browser's native dialog, and panels stack.
- **Page Layout** — A side menu page is flat on desktop, and the raised look is opt-in.
- **Persona** — Less space between the name, role and description.
- **Performance** — Faster start and response on busy phones, and sections far from the screen draw later.
- **Section** — On phones, a section action's buttons are full width anywhere in the body.
- **Tokens** — The secondary text color is darker, for better contrast.
- **Top Bar** — The date, clock and weather follow the site's timezone and use Meta lines.
- **Toolbar** — Less space below the bar.

### Migrating from v1.12.0
- Replace the runtime: copy `_site/assets/` over your assets folder.
- Run `NDS.init.audit()` on every page. It lists each old name the page still uses, with its replacement. The full list by release is on the [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page.
- **Accessibility** — `NDS.Accessibility.state.settings['font-step']` is always a number, 0 to 3. A Font Sizing tile press stored it as text (`'2'`), and the Visually Impaired mode as a number (`2`). A visitor's saved settings are read back as a number. Compare with `===` against a number.
- **Action rows** — A modal's `.nds-card-actions` no longer stack on a phone by themselves: add `nds-col-sm` to keep the stack. A panel or form footer whose buttons do not fit now wraps onto a second line: add `nds-col` to stack them instead.
- **Alert** — the `variant` option of `NDS.Alert.create()` is `status`, with no alias. An alert created with `variant` shows the default `info` status. An action's `variant` is unchanged.
- **Autocomplete** — With `data-strict`, text already in the field when it builds counts as a pick, so a server-filled value passes after the user tabs through the field. Check a value the server fills on the server, if it can be out of date.
- **Autocomplete** — `data-name` is `data-display-field`, the result field each row shows. With the old name, rows show the `Title` field.
- **Button** — A button no longer stretches to fill a column. Add `.nds-full` to one that should fill its container.
- **Button** — A `hidden` attribute on the `.nds-progress-circle` inside a button now keeps the circle hidden: remove it, since the button's `nds-progress` class shows the circle.
- **Button** — A badge you write by hand takes its count in `data-count`: `<span class="nds-badge">3</span>` becomes `<span class="nds-badge" data-count="3"></span>`. A text count still shows, but an accessibility checker reports it on a button with a label. `NDS.init.audit()` names each one (`badge-text`).
- **Button** — A `--btn-size`, `--btn-gap` or `--btn-indicator-size` in your stylesheet on a button with `nds-sm` or `nds-md` now wins over the class. Remove it where the class should set the size.
- **Button** — Nine on-color tokens put `oncolor` before the state, with no aliases: `--button-label-danger-primary-{state}-oncolor` is `--button-label-danger-oncolor-{state}`, `--button-label-transparent-{state}-oncolor` is `--button-label-transparent-oncolor-{state}`, and `--button-background-disabled-oncolor` is `--button-background-oncolor-disabled`. `NDS.init.audit()` names each one.
- **camelCase names** — every camelCase class, id and event is renamed to kebab case, with no aliases: `nds-wSideMenu` is `nds-has-sidemenu`, `ndsAccessibilityPanel` is `nds-accessibility-panel`, and so on. The [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page and `NDS.init.audit()` list each one. A few are more than a respelling: `nds-rowView` and `nds-colView` are `nds-horizontal` and `nds-vertical`, `showZoom` is `nds-zoom-badge`, `id="ndsThemeToggle"` is the `data-theme-toggle` attribute, and `nds-cardView` on a stepper is removed (see Stepper). A custom accessibility panel needs the new collapse ids for its active counts. In `_source/`, `nds-timeDate.js` and `nds-cityWeather.js` are replaced by `nds-clock.js`, `nds-date.js` and `nds-weather.js`, and the Digital Stamp files are `_digital-stamp.scss` and `nds-digital-stamp.js`.
- **Cards** — `.nds-card-status` and `.nds-card-checkbox` are removed: put the tag or the checkbox in `.nds-card-corner`, written first in `.nds-card-text`, the checkbox last; `.nds-full-width` on a card is removed, since a card now fills its container; `.nds-user` was removed (user cards went from 224px to 360px); centred cards lost the 1.5× block padding.
- **Cards** — A card fills its container. To keep the 1.x width, set `--card-width-max: 360px` on the card or its container. Put a row of cards in a [List](https://mazin-musleh.github.io/NDS-vanilla/components/list.html).
- **Cards** — `--img-ratio`, `--img-pos-x`, `--img-pos-y` and `--overlay` are now `--image-ratio`, `--image-pos-x`, `--image-pos-y` and `--image-overlay-opacity`, the names Image uses. Rename them where you set them on a card image.
- **Cards** — The color knobs name the property, with no aliases: `--card-title` is `--card-title-color`, and the same for `--card-subtitle`, `--card-text`, `--card-number` and `--card-rating`. `--card-border`, `--card-border-hover` and `--card-border-active` are `--card-border-color`, `--card-border-color-hover` and `--card-border-color-active`.
- **Chart** — `NDS.Chart.create(el, options)` on an element that has a chart no longer replaces it: it returns the chart unchanged. Call `el.ndsChart.setOptions(options)`, or `destroy()` and then `create()`.
- **Checkbox and Radio** — the field classes take the component names, with no aliases: `.nds-check-container` → `.nds-checkbox`, `.nds-radio-container` → `.nds-radio`, `.nds-check-group` → `.nds-checkbox-group`. The inputs take part names: `input.nds-check` → `.nds-checkbox-input`, `input.nds-radio` → `.nds-radio-input`. `.nds-radio` on an input now does nothing; it is the class of the field around it. `NDS.init.audit()` names each one.
- **Code** — the `code-example` class on a code tab panel does nothing: a panel in `.nds-tabs.nds-code` has no padding by itself. Component scripts still skip anything inside `<code>`, but no longer skip an element only because it is inside `.code-example`.
- **Code** — `data-nds-code-processed` is now `data-nds-code-highlighted`. To highlight a block again after you change its text, call `NDS.Code.highlight(code)`.
- **Core** — `NDS.triggerEvents(el)` is replaced by `NDS.setValue(el, value)`, with no alias. It writes the value and fires `input` and `change` (a checkbox or radio flips with a click, which fires them too); `{ change: false }` fires `input` only. `el.value = x; NDS.triggerEvents(el);` becomes `NDS.setValue(el, x);`. A controlled React field now sees the values NDS writes.
- **Core** — `NDS.cache` keys start with `nds-cache:` (they started with `nds_`). Old entries are not read again; they refill.
- **Cookies** — The cookie popup markup and `#ndsCookiesPopup` are removed: the script builds the panel, and a page's own `#nds-cookies-panel` in a `<template class="nds-panel-template">` replaces it. `#ndsCookiesAcceptBtn` and `#ndsCookiesDeclineBtn` become `data-cookies-action="accept|reject"`, and close is `data-panel-close`. `.nds-cookie-popup`, `.nds-cookie-popup-links` and `.nds-compact` are removed. `data-accept-title`, `data-accept-message`, `data-decline-title` and `data-decline-message` are removed: the Done view text is the `done_title` and `done` i18n keys. `NDS.consent.get()` may return `'custom'`. `nds:cookies:consent` fires on `document`, and a listener on the old popup never runs. The panel is `data-panel-static`, so an outside click does not close it.
- **Cookies** — If you copied the Google Analytics consent snippet, copy it again from the [Cookies](https://mazin-musleh.github.io/NDS-vanilla/ui-shell/cookies.html) page. It now sets all six consent keys, denies functionality and personalization storage by default, and applies a returning visitor's stored choice. The snippet reads the `nds-consent` cookie, which was `cookieConsent`. The dismissed notice is `nds-cookies-dismissed` (it was `cookieConsentDismissed`). Visitors see the consent notice once more.
- **Cookies** — the cookie helpers move out of `NDS.Cookies`, with no aliases: `NDS.Cookies.get`, `set` and `delete` are `NDS.cookie.get`, `set` and `delete`, `NDS.Cookies.getConsent()` is `NDS.consent.get()`, and `NDS.Cookies.show(view)` is `NDS.Cookies.open(view)`. `NDS.Cookies` is now the panel only: `init()`, `open()` and `close()`. Search your scripts for the old names: the audit cannot see script calls.
- **Copy** — on a copy button, `data-label` is renamed `data-copy-label` and `data-message` is renamed `data-copy-announce`. No aliases. Multiselect keeps its own `data-label`.
- **Date Picker** — "today" follows the visitor's timezone, or `data-timezone` on `<html>`. Before, it was always Riyadh: set `data-timezone="Asia/Riyadh"` to keep that. A picker with no `data-format` uses the nearest `data-date-format`, then `DD/MM/YYYY` as before.
- **Date Picker** — `CalendarConfig.hijri.gregorianToHijri(d)` → `NDS.Date.format(d, { calendar: 'hijri', format: 'DD/MM/YYYY' })`. `CalendarConfig.hijri.hijriToGregorian(y, m, d)` → `NDS.Date.parse(text, { calendar: 'hijri', format: … })`. `NDS.DatePicker.createHijriDate()` → no replacement: write a `{ day, month, year }` object.
- **Date Picker** — Only `data-calendar` picks the calendar (the nearest one, else Gregorian). A date in the other calendar is converted to the field's, whether the user types or pastes it or the page ships it in the field's `value`: `15/09/1447` in a field with no `data-calendar` becomes `04/03/2026`. A date the user writes converts when they leave the field, and a message under it names the date they wrote. Before, a year up to 1500 switched the field to Hijri. A Hijri form needs `data-calendar="hijri"` on the picker or on `<html>`. `NDS.DatePicker.Calendar` no longer has `detectCalendarTypeFromValue` or `detectCalendarTypeFromSingleValue`.
- **Date Picker** — Without `data-lang`, the calendar's words follow the nearest `lang`, not only the input's own: set `data-lang` on the input to keep one language. On `el.ndsDatePicker`, only `destroy()` stays public; its other methods and fields (`state`, `elements`, `render()` and the rest) are internal and start with `_`. Use `NDS.DatePicker.create(input)` and `destroy(input)`, the input's value and its `change` event.
- **Date Picker** — The calendar button's class is `nds-date-picker-toggle`, not `date-picker-toggle`. A button with the old class no longer opens the calendar.
- **Dates** — one `data-calendar="hijri|gregory"` sets the calendar for the content inside it, like `data-date-format`: on `<html>` for the site, or on any element. Date Picker, the top bar date and Sort read it. `.nds-hijri` on a Date Picker is removed: write `data-calendar="hijri"`. On the top bar date, `data-calendar="gregorian"` becomes `gregory`. No aliases; `NDS.init.audit()` names both.
- **Definition List** — `nds-item-title` and `nds-item-desc` are removed, and the Feature list structure with them. A list of features is a List: `ul.nds-list.nds-grid.nds-flat` with an `li.nds-card` for each item, the title in `.nds-card-title` and the text in `.nds-card-description`. A name and its value stay a Definition List, with `dt` and `dd`. See the [List](https://mazin-musleh.github.io/NDS-vanilla/components/list.html) page.
- **Definition List** — `nds-item-action` is `nds-definition-action`.
- **Definition List** — A transparent button in a side info value keeps its padding and height, as it does everywhere else. For a link that reads as text, write a plain link: `<a href="…">FAQ</a>`, with no button classes and no `nds-label`.
- **Deprecations** — v2.0.0 removes every name 1.x deprecated, with no alias: in Swiper, Cards, Numbers, Slider, Toolbar, Section and Footer, Forms, Filter, Drawer, the menus and the icons. The [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page and `NDS.init.audit()` list each one with its fix. Three need more than a new name. A Filter reset button needs `data-filter-action="reset"`: a refresh icon no longer makes one. A drawer no longer opens or locks by screen width: write `data-state="open"` on an item to start it open. A counter or number format in a card takes `.nds-card-number` for the number's look.
- **Docs site** — The showcase layer is removed: `docs-assets/js/nds-showcase.min.js`, `docs-assets/css/nds-showcase.min.css` and the `exclude_showcase` front matter key, which no longer does anything. Delete both files from a template copy, and the key from your pages.
- **Drawer** — the `--drawer-indicator-active` and `--drawer-indicator-hover` knobs, with no alias. The drawer's buttons draw the button indicator: set `--btn-indicator-selected` or `--btn-indicator-color` on `.nds-drawer .nds-btn`.
- **Source files** — each component has one name, from its class, for its files in `_source/`: `nds-tables.js` → `nds-table.js`, `nds-panels.js` → `nds-panel.js`, `nds-mainnav.js` → `nds-main-nav.js`, `nds-customselect.js` → `nds-custom-select.js`, `nds-forms.js` → `nds-form.js`, `nds-cooldown-button.js` → `nds-cooldown.js`, and the SCSS partials `_tables`, `_panels`, `_cards`, `_tags`, `_featured-icons`, `_feedback-icons`, `_mainnav`, `_cookie`, `_forms` and `_cooldown-button` → `_table`, `_panel`, `_card`, `_tag`, `_featured-icon`, `_feedback`, `_main-nav`, `_cookies`, `_form` and `_cooldown`. The built bundles keep their names: only a site that builds from these sources changes its paths. Doc pages take the same names, and an old link still opens the page.
- **Flex** — `.nds-flex` puts 8px between its children, not 16px. A column of cards or sections that should stay 16px apart takes `style="--gap: var(--spacing-xl);"`, or `--gap` in a class of your own. A form's field stack and a List of cards keep 16px with no change.
- **JavaScript names** — each namespace is its component's class name in PascalCase, with no aliases: `NDS.Forms` → `NDS.Form`, `NDS.Tables` → `NDS.Table`, `NDS.Mainnav` → `NDS.MainNav`, `NDS.CooldownButton` → `NDS.Cooldown`, `NDS.TagInput` → `NDS.Taginput`, `NDS.OTP` → `NDS.Otp`. Instances: `el.ndsTagInput` → `el.ndsTaginput`, `el._ndsSwiper` → `el.ndsSwiper`, `el._ndsDatePicker` → `el.ndsDatePicker`, `el._ndsToc` → `el.ndsToc`, `el._ndsSideInfo` → `el.ndsSideinfo`. The init stamps `data-nds-tables-initialized` and `data-nds-cooldown-button-initialized` are `data-nds-table-initialized` and `data-nds-cooldown-initialized`. Core modules are lowercase: `NDS.Init` → `NDS.init`, `NDS.State` → `NDS.state`, `NDS.Status` → `NDS.status`, `NDS.Audit` → `NDS.audit`. Search your scripts for the old names: the audit cannot see script calls.
- **JavaScript methods** — methods use one verb per meaning, with no aliases. A re-measure or re-read is `refresh()`, such as Selection `recount(list)` → `refresh(list)`. Form `validateForm(el)` → `validate(el)`, and the field checks moved to their components, such as `validateRadioGroup(group)` → `NDS.Radio.validate(group)`. `setStatus` takes `(el, status, { message, permanent })`. Swiper `slideTo(i, animate)` → `goTo(i, { instant })`. The [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page lists each one. Search your scripts for the old names: the audit cannot see script calls.
- **JavaScript methods** — public names read verb first, in whole words, with no aliases, such as `NDS.isRTL` → `NDS.isRtl`, `NDS.rafThrottle` → `NDS.throttleToFrame` and Chart `update()` → `setOptions()`. The [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page lists each one. Search your scripts for the old names: the audit cannot see script calls.
- **Events** — every event follows `nds:component:action`, with no aliases, such as `nds:formValid` → `nds:form:valid`, `nds:upload:beforeUpload` → `nds:upload:start` and `nds:tab:change` → `nds:tabs:change`. The `detail` of each event is the same. The [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page lists each one. `NDS.init.audit()` cannot find them, because a page cannot see its listeners: search your scripts for the old names.
- **FAB** — `data-fab-pos` is `data-fab-side`, and `data-fab-dock-pos` on a dock you write is `data-fab-dock-side`: the word Panel uses in `data-panel-side`. With the old name, a FAB docks on its panel's edge.
- **Feedback** — A message with no size class has a 16px icon, not 24px: add `nds-md` where you want the old size. `NDS.Feedback.create()` with no `size` writes no size class, so CSS that selects its `nds-sm` no longer matches.
- **File Upload** — `.nds-file-upload` is renamed `.nds-upload`, with no alias.
- **File Upload** — `nds:upload:removed` now also fires for `clearAllFiles()`, a form reset and Single replacing a file, so a listener that deletes server copies sees each of them; a form reset empties the list; code that waits on `status === 'uploading'` at the end of an upload sees `processing` first; file rows no longer carry `data-index`.
- **File Upload** — The parts take the `nds-upload-` prefix: `nds-file-input` is `nds-upload-input`, `nds-browse-btn` `nds-upload-browse`, `nds-drop-hint` `nds-upload-drop-hint`, `nds-remove-file` `nds-upload-remove` and `nds-error-message` `nds-upload-error`. Rename them in your file row template too: a remove button with the old class does nothing. The `nds-file-*` row parts stay.
- **File Upload** — `NDS.Upload.create(el, options)` on a field that has started no longer merges the options: it returns the field unchanged. Call `el.ndsUpload.setOptions(options)`.
- **Filter** — `criteria.search` keeps `& " ' < >` and its full length when it comes from the URL, and its letter case as typed: lowercase it yourself if you compare it. Escape it if you print it as HTML. After a client-mode sort, `nds:filter:change` carries numbers in `totalItems`, `visibleItems` and `hiddenItems`, so a check for `null` there never matches. `detail.criteria` on `nds:filter:submit` and `nds:filter:request` is a copy: add request data through `hiddenInputsContainer`.
- **Filter** — A server that reads `filter-{name}` reads `{name}`. A checkbox or switch group's values arrive as repeated keys, in the request and the URL, not comma-joined. A slider or date range arrives as two keys, `{name}-min` and `{name}-max`, or the names you give each end; read them in place of `fee=200-1500` and `updated=2026-10-06..2026-10-18`.
- **Filter** — `nds:filter:change` fires after the URL, the chips and the page update, on every path. When a filter applied, it fired before them, so a listener that reads `location.search` or the current page saw the old values.
- **Filter** — events name the filter by its element, as other components do. `detail.filter` on `nds:filter:change`, `nds:filter:reset` and `nds:filter:clear` is the element the event fires on: read the instance from `detail.filter.ndsFilter`. `nds:filter:ready` carries `{ instance }`: read `e.detail.instance` where you read `e.detail`. `NDS.Filter.whenReady()` still passes the instance.
- **Flex and Grid** — `--gap`, `--row-gap`, `--col-gap`, `--justify` and `--align` do not pass down: each one styles only the element it is set on. Before, a value on a Flex or Grid also reached every Flex, Grid, Stepper, Swiper and Definition list inside it. A layout that relied on that sets it on each inner element. A horizontal Section and a Definition list still take `--gap` from their own root.
- **Forms** — A `method="post"` form answered by a download or a `204` keeps its button spinning and takes no second submit until the page reloads: add `data-no-pending` to it.
- **Forms** — Remove `nds-phone` from the `<input>`. Write `nds-formatted` and `data-format="phone"` on its `.nds-form-container`: `<div class="nds-form-container nds-formatted" data-format="phone">`. With the class, the field no longer takes its shape. The audit names each one left.
- **Forms** — A phone field with a code submits `+966551234567`, not `551234567`. A field with a country picker whose items' `data-value` is the code (`+966`) needs no change. Add `<input type="hidden" value="+966">` to the prefix of a field with a fixed code: without it, the field keeps the leading zero and sends `0551234567`. Update a server that adds the country code itself, or that joins the picker's `data-select-name` field to the number: the phone field now holds the whole number. The picker's field still submits.
- **Forms** — Mark your own spinner slot in a field's `.nds-form-action` with `data-loading-slot`. `.nds-loading` there no longer marks it. `.nds-loading` on the field is unchanged.
- **Forms** — The show-password toggle carries `data-state="shown"` while the password shows, not the `show` class. Key your CSS on `.nds-toggle-password[data-state~="shown"]`.
- **Grid** — `NDS.gridLastRow.update(el)` is `NDS.Grid.refresh(el)`, with no alias. A `.nds-grid.nds-divided` that is not a Definition List now draws lines between its items: remove `nds-divided` from it if you do not want them.
- **Head** — Copy the head's inline style and script again from the [Head](https://mazin-musleh.github.io/NDS-vanilla/ui-shell/head.html) page: a browser that blocks storage no longer blanks the page, the hero overlay reads `--background-image-overlay`, and a theme stylesheet right after the critical CSS applies. Update its CSP hash. `data-nds-fonts-loaded` and `data-nds-icons-loaded` on `<html>` are removed: icons hold their box from the first paint, so remove any rule keyed on them.
- **Hero** — `--overlay` on a hero slide is now `--hero-overlay-opacity`. Rename it in each `.nds-hero-image-wrapper` style. `--hero-overlay-color` is new: it changes one slide's tint color.
- **Helper Classes** — `.nds-required-notice` is removed: use `.nds-note` with `data-status="error"`. The note has no space below it; add `nds-block` for a 32px gap.
- **Hero** — the sub hero's image knob `--hero_image` is renamed `--hero-image`, and `--hero-mask-angle`, `--hero-mask-from` and `--hero-mask-to` are renamed `--hero-image-fade-angle`, `--hero-image-fade-from` and `--hero-image-fade-to`. No aliases.
- **Hidden** — the `data-hidden` tokens `mobile`, `tablet` and `desktop` are removed: use `sm`, `md` and `lg`. `.sr-only` is removed: use `.nds-sr-only`.
- **Image Popup Viewer** — `.nds-ipv-thumbnail` no longer gives the image a 200px size and a crop: it only sets the pointer. Size the image with your own styles.
- **Image Popup Viewer** — `window.ndsIPV` and `NDS.Ipv.create()` are removed, with no alias: the viewer is driven from its namespace, like Backdrop. `viewer.open(img)` → `NDS.Ipv.open(img)`, `viewer.close()` → `NDS.Ipv.close()`, `viewer.showPrev()` and `showNext()` → `NDS.Ipv.prev()` and `next()`, `viewer.resetTransform()` → `NDS.Ipv.resetZoom()`, `viewer.toggleUI()` → `NDS.Ipv.toggleControls()`, `viewer.destroy()` → `NDS.Ipv.destroy()`.
- **Internationalization** — `NDS.langKey` is removed: use `NDS.lang`. `NDS.i18n.load(component, scopes)` and `NDS.i18n.apply()` are removed: markers translate themselves, and `await NDS.i18n.getStrings(section, {}).load()` waits for a section's words. `assets/i18n/accessibility/` and `assets/i18n/ipv/` moved into the `accessibility` and `ipv` sections of `assets/i18n/{lang}.json`: a site that edited a file there moves its words into `window.NDS_I18N`. `window.NDS_I18N.<section>` now replaces only the keys it sets. A custom Accessibility panel renames its markers to `data-i18n="accessibility.key"`, and `NDS.init.audit()` names each one. Filter finds a search box's clear button by `.nds-clear` only.
- **JavaScript API** — `create()` on Accordion, Autocomplete, Breadcrumb, Dropmenu, Expandable and Toc returns `null` when the markup is incomplete; check the result before calling a method on it.
- **JavaScript API** — `reinit()` is removed from every component, with no alias. Call `init()`: it does the same.
- **Loader** — `window.NDSAssetBase` and `window.NDS_ASSETS_BASE` are replaced by `window.NDS_ASSETS_PATH`, with no alias. Set it to the `assets/` folder: the value `NDS_ASSETS_BASE` took, one level above the `js/` folder `NDSAssetBase` named. It sets where the bundles and the language files load from, and it wins over the folder of `nds-main.min.js`. The name matches `NDS_I18N_PATH`. `window.NDSInitConfig` is renamed `window.NDS_INIT_CONFIG`, with the same value.
- **Loader** — `NDS.loadExtras()` is removed: use `NDS.init.mount(el)`, or `NDS.loadBundle(name)`. Editor, Chart and Code left the extras bundle for their own (`nds-editor.min.js`, `nds-chart.min.js`, `nds-code.min.js`): ship the three new files beside the others, and change `NDS.loadBundle('extras')` before a Chart call to `NDS.loadBundle('chart')`. A registry entry in `NDS.init.components` may now leave out `init` (it defaults to `NDS[name].init()`); `universal` is gone, and `selector: null` means every page.
- **Loader** — The `<html>` switches take no value and no `nds-` prefix: `data-nds-auto-init="false"` is `data-no-auto-init`, and `data-nds-disable-all="true"` is `data-no-init-all`. The old names are not read, so every component starts at load. `NDS.init.audit()` names them.
- **Main Navigation** — its classes and ids are renamed, with no aliases, such as `nds-dropdown` → `nds-has-menu`, `nds-PAB` → `nds-pinned` and `ndsMainNav` → `nds-main-nav` (the menu button's `aria-controls` too). `NDS.init.audit()` names every old class or id still in a page's nav, and the [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page lists each one. A menu trigger writes `data-state="open"` while its menu is open, not `active`. `NDS.Mainnav.toggleNavbar()` and `toggleDropdown(event)` are removed: use `open()`, `close()`, `toggle()`, `openMenu(trigger)` and `closeMenus()`.
- **Modal** — Make each modal a `<dialog class="nds-modal">`, and drop its `role="dialog"`, `aria-modal`, `aria-hidden` and `hidden`. `NDS.init.audit()` flags a modal that is a `<div>`.
- **Multiselect** — `instance.getSelected()` is `getValues()` and `instance.reset()` is `clear()`, with no aliases. `NDS.Multiselect.getValues(el)` and `NDS.Multiselect.clear(el)` do the same without an instance.
- **National Day 96** — Type 2 is the pack's new default hero. To keep the single slide, add `data-type="1"` to the pack's `<script>` tag.
- **Numbers** — numbers follow the `lang` of the page, in Latin digits (0 to 9) (before, the browser's language, so an Arabic browser showed Arabic-Indic digits on an English page). This covers `NDS.formatNumber`, so Pagination, Selection, Slider and Filter numbers change with it. `nds-number-format` no longer formats a `nds-counter-value`: the counter formats its own number.
- **Numbers** — `data-decimals` on a counter: write `data-target` with the decimals you want.
- **Panels** — Make each panel a `<dialog class="nds-panel">` and drop its `hidden` attribute. A modal panel now covers the main navigation. `NDS.init.audit()` flags a panel on any other element.
- **Part sizes** — A size knob on a wrapper now wins over a size class inside it. With `--avatar-size: 80px` on a list, an avatar with `nds-sm` in it is 80px, not 32px. Move the knob onto the parts it should change. The same holds for `--featuredicon-size`, `--star-size`, `--progress-size`, `--chip-size` and `--feedback-size`.
- **Persona** — `nds-persona-desc` is `nds-persona-description`, and its knobs `--persona-desc-FS`, `--persona-desc-LH` and `--persona-desc-color` are `--persona-description-FS`, `-LH` and `-color`.
- **Popups** — `data-portal`, `data-no-portal` and `data-dropmenu-portal` are removed, with no alias: an open menu sits in the top layer and stays inside its wrapper. `NDS.portal()`, `unportal()`, `needsPortal()`, `stackingZ()`, `closest()`, `queryAll()` and `querySelector()` are removed: use the DOM's own `closest()` and `querySelectorAll()`, which now reach an open menu. The `ndsDropmenuItem` event is removed: in a click listener, read `e.target.closest('.nds-dropmenu-item')`.
- **Page Layout** — `nds-full-width` on `body` is removed, with no alias: put it on `.nds-content-layout` (`layout_class` in page front matter). The header and the footer follow it.
- **Page Layout** — `.nds-main-content` is renamed `.nds-content`, and its knobs `--main-padding-block`, `--main-padding-inline` and `--main-gap` are renamed `--content-padding-block`, `--content-padding-inline` and `--content-gap`. No aliases.
- **Section** — `nds-noBg` on a section is removed, with no alias: use `nds-ghost`. On a page with no side column, `nds-noBg` also added space above and below a run of such sections; `nds-ghost` does not, so set `--section-margin-block-start` and `--section-margin-block-end` where you need it.
- **Section** — `.nds-section-shape` is removed: put an `.nds-section-icon` inside `.nds-section-title`. Its knob `--section-shape-size` is renamed `--section-icon-size`. No aliases.
- **Section** — `nds-minimal` on a float action or a button is removed. Write `data-hidden="sm sr"` on each button's label: on phones the button shows only its icon, square.
- **Section** — `nds-max-width` on a section body is `nds-breakout`, the name Cards use for a part that runs to their edges. No alias. It works only on a body that is a direct child of the section. It runs one page gutter past the content, so on a screen wider than the max width it stops short of the screen edge. Beside a side menu it stays in the content column.
- **Selection** — the `nds:table:selection` event. Listen for `nds:selection:change` on the list: its `detail` is `{ list, items, count, total }` (it was `{ selectedCount, totalCount, selectedRows, selectedIndexes }`).
- **Selection** — `NDS.Selection.reinit()` is removed. `NDS.Selection.init()` does not count every list again: call `NDS.Selection.refresh()` for that.
- **Side Info** — `nds-sm`, `nds-md` and `nds-lg` on `.nds-sideinfo` are removed, with no alias. The column is 400px wide, or 300px when it holds a table of contents: set `--nds-sideinfo-width` for another width. `--nds-sideinfo-width` is no longer set on `:root`. Below 960px the column is always full width. `nds-sticky-sm` and `nds-sticky-md` work without `nds-sticky`. Fixed: a sticky column beside the title stayed sticky only while short. Added: several cards in one column stack with a gap, set by the new `--nds-sideinfo-gap` knob (default `--spacing-4xl`).
- **Side Info** — `nds-card` on the `aside` itself is removed. Move `nds-card`, with `nds-stroke` and `nds-shadow`, to a `div` inside the `aside`: the aside is the column, and the card sits in it. Set `--card-width` on the element with `.nds-card`, not on the aside: on the aside it no longer reaches nested cards.
- **Side Info** — `instance.updatePosition()` and `instance.updateStickyState()` are removed, with no alias: the column re-measures itself when the hero resizes or the fonts load. Remove the calls.
- **Side Menu** — the `--toggle-height` knob is renamed `--nds-sidemenu-toggle-height`, and `--toggle-transform` is removed. No aliases. The side menu no longer styles `li.redirect.external`: remove the `redirect` class.
- **Slider** — `NDS.Slider.reinit(el)` is `NDS.Slider.refresh(el)`. `NDS.Slider.init()` does not measure again.
- **Sort** — `data-sort-dir` is renamed `data-sort-order`, and `dir` is `order` everywhere: `initialState: { key, order }`, `urlSync: { keyParam, orderParam }` (was `dirParam`), `apply(key, order)`, and the `getState()`, `onChange` and `nds:sort:change` results. Tables' `getSortDirection()` → `getSortOrder()`. No aliases. A Filter's sort writes `?sort=price&order=desc`: read `order` on the server. A link with `dir=desc` opens ascending. A sort in the URL now wins over `initialState` and over a sorted state written in the markup, and the markup follows it; before, `initialState` won and a shared link opened in the server's order.
- **Sort** — `detail.sort` on `nds:sort:change` is the root element: read the instance from `detail.sort.ndsSort`.
- **Status Section** — `.nds-404` is removed: use `.nds-status-section`.
- **Stepper** — `NDS.Stepper.setFallback()` and `getFallback()` are removed: write `nds-vertical` or `nds-radial` on the stepper instead. The `nds-horizontal-lg`, `nds-vertical-lg` and `nds-radial-lg` classes are removed: the layout class is the desktop layout, and `-sm` / `-md` set phones and tablets. `nds-radial nds-vertical-lg` becomes `nds-vertical nds-radial-sm nds-radial-md`. The deprecated `NDS.Stepper._applyLayout()` and `NDS.Stepper._stamp()` are removed: call `NDS.Stepper.init()`.
- **Stepper** — `nds-cardView` on a stepper is removed, with no `nds-card-view` in its place: put `nds-card` on the stepper, on every step or on every step's content.
- **Stepper** — `next()` on the last step moves the stepper one past it, the same state a `data-current` past the last step gives. `data-current`, `instance.currentStep` and `detail.currentStep` of `nds:stepper:change` are the step count plus one once the flow is completed (they stayed at the last step). A further `next()` returns `false` (it returned `true`). `NDS.Stepper.get(id)` finds only a stepper that is in the page. A listener that compares `currentStep` to the step count must also test the count plus one. These are behavior changes, so `NDS.init.audit()` does not flag them.
- **Swiper** — A swiper far down the page has no `data-nds-swiper-initialized` and no `slidesPerView` at load, even after `NDS.init.ready`. Code that reads its state at load calls a method first, such as `goTo()`, or waits for the attribute.
- **Swiper** — The current bullet carries `data-state="active"`, not `data-status`. Key your CSS on `.nds-bullet[data-state~="active"]`.
- **Switch** — `.nds-switch-container` is renamed `.nds-switch`, and the element that held the input and the track is renamed `.nds-switch-toggle`, with no aliases. `nds:switch:change` now fires from `.nds-switch-toggle`. `NDS.init.audit()` names each one.
- **Tables** — the `nds:table:sort` event. Listen for `nds:sort:change` on the table: `detail.key` is the column index and `detail.order` the order.
- **Tables** — `table-actions`, `actions-column` and `checkbox-column` are renamed `nds-table-actions`, `nds-actions-column` and `nds-checkbox-column`. No aliases.
- **Tables** — `nds-mask` (the scroll-edge fade) and its `--mask-fade-distance` knob are removed, with no replacement: delete the class. The scroll box still writes `has-more`, `at-start` and `at-end` in its `data-state`.
- **Tabs** — The unprefixed `center` class is removed. Use `nds-center` on the tab list.
- **Tags** — a status tag's solid look `nds-inverted` is `nds-dark`, as on Featured Icon. Normal tags no longer take a solid look (`nds-inverted`) or `nds-ghost`, and status tags no longer take `nds-outline`. An icon-only tag now keeps its `.nds-label` readable by screen readers; existing icon-only markup renders the same, and adding a label to it is recommended, not required.
- **Tokens** — `--img-overlay-color` is renamed `--background-image-overlay`. `--colors-tertiary-alpha-10` and `--colors-tertiary-alpha-20` are removed: use `color-mix(in srgb, var(--colors-tertiary-500) 10%, transparent)` (and `20%`). No aliases. `NDS.init.audit()` names each (rows in `_data/migrations.yml`). Copy the Hajj pack again: the old one sets the old overlay name.
- **Toolbar** — `nds-bar-row`, `nds-bar-start`, `nds-bar-end` and `nds-bar-text` are renamed `nds-toolbar-row`, `nds-toolbar-start`, `nds-toolbar-end` and `nds-toolbar-text`. No aliases; `NDS.init.audit()` names each, and its new `toolbar-part` check flags a part outside a `.nds-toolbar`.
- **Top Bar** — Today, the clock and the weather are no longer ids, and the script no longer writes their icons. `#nds-date` is a `<time data-date-today data-calendar="hijri" data-date-format="long" data-date-era>`, and `#nds-real-time-clock` a `<time class="nds-clock">`, each in a `.nds-meta-item` with its own icon. `#nds-weather-info` and `#nds-city-name` are one `.nds-weather`, with `data-latitude` and `data-longitude`, and the city's name as text in a `.nds-weather-city` inside it. `data-city` and `data-city-en` are removed: write the name in the page's language, or mark it with `data-i18n`. Copy the markup from the [Top Bar](https://mazin-musleh.github.io/NDS-vanilla/ui-shell/topbar.html) page. `nds-text-icon` is removed. The city lookup from coordinates is removed: write the names.
- **Top Bar** — `NDS.TimeDate` and `NDS.CityWeather` are removed. The loader starts Today, the clock and the weather; `NDS.Date.fill()`, `NDS.Clock.init()` and `NDS.Weather.init()` write them again. `NDS.TimeDate.getHijriDate()` → `NDS.Date.format(NDS.Date.getToday(), { calendar: 'hijri', format: 'D M YYYY' })`.
- **Digital Stamp** — The top bar opens and closes the stamp. The tab needs `data-topbar-toggle` and `type="button"` (drop `role="button"`), and `#nds-digital-stamp` needs `class="nds-topbar-expander"`: without them the tab opens nothing. Wrap the notices and the register in a `.nds-topbar-expander-content` inside the `.nds-content-wrapper`: it holds the stamp's space above and below. `NDS.DigitalStamp.open()`, `close()`, `toggle()` and `isOpen()` → `NDS.Topbar.open('nds-digital-stamp')` and the others. `nds:digital-stamp:opened` and `closed` → `nds:topbar:opened` and `closed`, with the stamp in `detail.expander`. See the [Digital Stamp](https://mazin-musleh.github.io/NDS-vanilla/ui-shell/digital-stamp.html) page.
- **Icons** — 16 content icons take the Hugeicons names, with no aliases: `hgi-layout-2-column` is `hgi-layout-two-column`, and `hgi-cplusplus` is `hgi-cpp`. The old class shows no icon. `NDS.init.audit()` names each one. The [Migration](https://mazin-musleh.github.io/NDS-vanilla/guides/migration.html) page lists them all.
- **User Feedback** — the widget's form no longer has `action="/submit" method="POST"`: add your endpoint as `action`, or nothing is sent. The answer and Submit buttons lose `aria-label`s that repeated their text, and Submit loses the unused `data-answer="submit"`. A dismissed success message no longer resets the widget.
- **Voice Input** — `data-target` is removed. Use `data-voice-target`.
